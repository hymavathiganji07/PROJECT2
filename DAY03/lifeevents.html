📚 Tech Glossary

HTML
HTML (HyperText Markup Language) is used to create and structure web pages using elements like headings, paragraphs, images, and links. It forms the basic building block of websites and works together with CSS and JavaScript to design interactive pages.
CSS
CSS (Cascading Style Sheets) is used to style and design web pages by controlling colors, fonts, layouts, and spacing. It makes websites attractive, responsive, and user-friendly by separating content from presentation.
JAVA
Java is a high-level, object-oriented programming language used to build secure and platform-independent applications. It is widely used in web applications, mobile apps (Android), enterprise software, and backend development.
